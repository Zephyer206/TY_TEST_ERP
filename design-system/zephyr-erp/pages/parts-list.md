## Motion: Minimal Updates Only

- **Row hover:** `150ms ease` background transition
- **Sorting indicator:** Instant (0ms) — no animation delay
- **Batch selection:** Instant checkbox state
- **Filter updates:** No animation, instant re-render
- **Pagination:** Instant navigation (no page fade)

**Rationale:** Manufacturing users scan hundreds of rows per session. Motion distracts from data absorption.

## Business Display Rules (ERP-Specific)

### Column Visibility Rules

1. **Never show internal autogenerated IDs** in list view
   - ❌ `part.id`, `material.id`, `tooling_work_part.id`
   - ✓ Show `part_number`, `material_grade`, `customer_part_number`

2. **Suppress irrelevant customer aliases**
   - If viewing "Customer A" parts, omit Customer A's column (redundant)
   - Show other customer aliases only when they exist

3. **Excel original values hidden by default**
   - Only show "Excel Original" column when user explicitly toggles it
   - Visual indicator when cell value differs from Excel import

4. **Modulus vs. Cavity disambiguation**
   - Column header: "模数" for shared mold module count
   - Column header: "穴数" for part-specific cavity count
   - Never use generic "Cavities" label

### Row Actions (Minimal)

- **Single-click:** Select row
- **Double-click:** Navigate to detail view
- **Right-click:** Context menu (Edit, Delete, Export)
- **Bulk actions:** Toolbar buttons (disabled when selection empty)

### Sorting & Filtering

- **Default sort:** Most recently modified first
- **Numeric columns:** Sort numerically (not lexically)
- **Date columns:** ISO format sort (YYYY-MM-DD)
- **Multi-column sort:** Shift+click on headers

## Accessibility

- **Keyboard Navigation:**
  - Tab: Move between toolbar controls
  - Arrow keys: Navigate table rows (when table focused)
  - Enter: Open detail view for selected row
  - Space: Toggle row selection
  - Ctrl+A: Select all visible rows

- **Screen Reader:**
  - Table caption: "Parts inventory list, {count} items"
  - Column headers: aria-label with sort state
  - Row selection: aria-selected state
  - Loading state: aria-live region

---

## Anti-Patterns for Lists

- ❌ Infinite scroll (use pagination for predictable data position)
- ❌ Decorative row animations on load
- ❌ Hover tooltips for non-truncated content
- ❌ Client-side filtering beyond 1000 rows (use server filtering)
- ❌ Auto-refresh without user control
- ❌ Modal dialogs for row actions (use detail view or inline edit)
