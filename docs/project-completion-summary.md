## 🎓 学到的经验

### SQLAlchemy 关系配置要点

1. **双向关系必须同步**
   ```python
   # ModelA
   model_b = relationship("ModelB", back_populates="model_a")
   
   # ModelB  
   model_a = relationship("ModelA", back_populates="model_b")
   ```

2. **外键必须明确**
   ```python
   foreign_id = mapped_column(ForeignKey("table.id"))
   ```

3. **自引用需要 remote_side**
   ```python
   parent = relationship("Model", remote_side=[id])
   ```

### 部署经验

1. **.env 文件路径**需要根据运行目录调整
2. **Python 字节码缓存**可能导致旧代码问题
3. **端口占用**需要彻底清理进程
4. **密码哈希**要使用正确的库和版本
