## 🔧 快速启动前端

### 1. 安装依赖
```bash
cd frontend
npm install
```

### 2. 配置后端 API 地址

检查 `src/utils/request.ts`，确保 baseURL 指向：
```typescript
const baseURL = 'http://127.0.0.1:8000/api/v1'
```

### 3. 启动开发服务器
```bash
npm run dev
```

通常会运行在：http://localhost:5173

### 4. 测试登录
- 访问 http://localhost:5173
- 使用 admin/123456 登录
- 查看是否成功跳转到仪表盘
