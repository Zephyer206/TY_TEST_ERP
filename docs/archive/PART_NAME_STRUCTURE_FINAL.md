# 零件名称数据结构方案（完整三级版）

## 正确理解

用户明确要求：**完整的三级分类结构**

### 数据结构

```
一级分类（零件主名称）- 必填
  └─ 二级分类 - 可选
      └─ 三级分类（客户零件名称）- 可选
          └─ 备注 - 可选
```

### 具体示例

```
弹簧片 (一级分类 - 必填)
├─ 标准型 (二级分类)
│  ├─ 摩擦片保持 (三级分类 - 客户名称)
│  │  └─ 用于A车型 (备注)
│  └─ 摩擦片保持(右) (三级分类 - 客户名称)
│     └─ 右侧安装 (备注)
├─ 加强型 (二级分类)
│  └─ XX客户定制 (三级分类 - 客户名称)
│     └─ 特殊工艺 (备注)
└─ (无二级分类)
   └─ 通用弹簧片 (三级分类 - 客户名称)
      └─ 标准件 (备注)

报警器 (一级分类 - 必填)
├─ 声光型 (二级分类)
│  └─ 客户B型号 (三级分类 - 客户名称)
│     └─ 带LED (备注)
└─ 蜂鸣型 (二级分类)
   └─ 标准蜂鸣器 (三级分类 - 客户名称)
      └─ 通用型 (备注)
```

### 选择场景

**场景1：只填一级分类**
- 第一列：弹簧片
- 第二列：点击"直接选择"（跳过二级）
- 第三列：留空或选"标准件"
- 结果：只有一级分类

**场景2：一级 + 二级**
- 第一列：弹簧片
- 第二列：标准型
- 第三列：留空或选"标准件"
- 结果：有一级和二级分类

**场景3：完整三级**
- 第一列：弹簧片
- 第二列：标准型
- 第三列：摩擦片保持
- 结果：完整三级分类

## 级联选择器数据构建逻辑

```javascript
const buildPartNameCascader = () => {
  // 第一层：按一级分类分组
  const primaryMap = new Map()

  partNames.value.forEach(part => {
    const primary = part.primary_category
    
    if (!primaryMap.has(primary)) {
      primaryMap.set(primary, new Map())
    }
    
    const secondaryMap = primaryMap.get(primary)
    const secondary = part.secondary_category || '直接选择'
    
    if (!secondaryMap.has(secondary)) {
      secondaryMap.set(secondary, [])
    }
    
    // 第三层：客户名称
    secondaryMap.get(secondary).push({
      id: part.id,
      label: part.customer_part_name || '标准件',
      value: part.id,
      remark: part.remark
    })
  })

  // 转换为级联选择器格式
  partNameCascaderOptions.value = Array.from(primaryMap.entries()).map(([primary, secondaryMap]) => ({
    label: primary,  // 第一列：弹簧片
    value: primary,
    children: Array.from(secondaryMap.entries()).map(([secondary, items]) => ({
      label: secondary,  // 第二列：标准型
      value: `${primary}-${secondary}`,
      children: items    // 第三列：摩擦片保持
    }))
  }))
}
```
