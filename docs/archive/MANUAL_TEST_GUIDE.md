### 5. 报价页面三级级联选择器测试

**访问路径**: http://localhost:5175/quotes

**测试步骤**:
1. 点击"新建报价"按钮
2. 点击"零件名称"的级联选择器

**预期结果**:
- 打开三级级联选择面板
- **第一列**显示：弹簧片、报警器
- 点击"弹簧片"后，**第二列**显示：弹簧片、直接选择
- 点击"弹簧片"（二级）后，**第三列**显示：标准件、摩擦片保持、摩擦片保持(右)

**级联结构验证**:
```
弹簧片 (一级)
  └─ 弹簧片 (二级)
      ├─ 标准件 (三级)
      ├─ 摩擦片保持 (三级)
      └─ 摩擦片保持(右) (三级)

报警器 (一级)
  └─ 报警器 (二级)
      └─ 标准件 (三级)
```
