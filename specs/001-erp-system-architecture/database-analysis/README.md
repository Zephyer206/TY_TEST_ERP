# 数据库分析文档

本目录只记录数据库现状、差异和维护方法，不再维护独立目标设计。

## 唯一权威设计

[`../data-model.md`](../data-model.md)

## 本目录允许包含的内容

- `current-schema.md`：实际数据库结构快照。
- `gap-analysis.md`：实际数据库与权威设计的差异。
- `maintenance-guide.md`：结构快照和差异报告的维护方法。
- 旧 `*-final.md` 文件：只保留跳转入口，兼容历史链接。

## 规则

- 本目录不得新增字段、实体或关系决策。
- `current-schema.md` 描述“现在是什么”，不表示“目标应该是什么”。
- `gap-analysis.md` 的目标端必须引用 `../data-model.md`。
- 发现旧设计冲突时，直接修改或废弃冲突内容，不再建立新的“最终版”文件。
