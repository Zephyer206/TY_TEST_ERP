# Feature Specification: 移动辅助工作台

**Feature Branch**: `006-mobile-companion`
**Status**: Implemented foundation, pending QR and production-session phases

## Scope

手机端是电脑 ERP 的辅助入口，不复制完整桌面业务。当前范围包括：价格查询、零件查询、生产计划/生产状态查看、库存与包装发货查看、登录和扫码入口。售后模块暂不进入手机端。

## User scenarios

1. 业务或管理人员在手机上按客户和件号查询价格及零件核心参数。
2. 资材或生产人员查看生产计划、订单量、剩余量、材料、TWP 和资材确认状态。
3. 仓库人员查询库存、包装状态和发货状态。
4. 现场人员进入扫码入口，后续通过二维码定位零件、模具、机台或包装记录。

## Non-goals

- 不在手机端重做生产排产、售后客户档案或完整编辑工作台。
- 当前不提供现场报工提交；生产会话和二维码扫描器完成后再开放。
- 不将售后单件/安装包入口加入手机底部导航或更多菜单。

## Acceptance criteria

- 360x800、390x844、844x390 和 768x1024 视口下无横向滚动。
- 未登录访问业务路由时回到登录页；401 清理移动端登录状态。
- 查询、生产、交付和扫码四个主入口均能实际打开；接口异常显示可理解的提示。
- 移动端使用 `/api/v1`，开发环境通过 `VITE_DEV_API_TARGET` 配置后端地址，不写死公网地址。

## Later phases

- 二维码：优先调用浏览器摄像头权限，失败时保留手动输入兜底；解析结果统一进入 `/qr/lookup`。
- 现场报工：先从扫码结果或生产会话取得 `session_id`，再开放良品/报废数量提交。
- 离线只读缓存和弱网重试在核心查询稳定后评估。
