# Feature Specification: 客户 PPAP 资料档案

**Created**: 2026-10-20  
**Status**: Confirmed in discussion; implementation acceptance pending

## Overview

在零件模块下增加 PPAP 子模块。天越、盖博均管理本公司向客户提交的 PPAP，保存已经完成的 Excel/PDF 文档并在线查看。质量部门维护，其他岗位只读。

## User Scenarios & Testing

### User Story 1 - 建立公司和客户资料档案 (P1)

质量人员建立档案，以现有资料文件夹名称作为业务名称，例如 `TYBU-Q0015(10020531)回位簧 PPAP 成型机`。档案可关联一个或多个零件、安装包及模具。

**Acceptance**:
1. 天越、盖博分别显示本公司档案；刷新后记录仍存在。
2. 名称支持手工录入和按模具号、件号、产品名、模具类型组合；系统另行生成稳定台账号。
3. 关联对象取自所选公司及客户，同一档案可同时关联多个零件和安装包。
4. 按名称、模具号、件号、产品名和客户查询档案；可从零件/安装包档案查看关联 PPAP。

### User Story 2 - 目录管理和在线阅读 (P1)

质量人员在资料包根目录和多级子文件夹中上传已经完成的 Excel/PDF；其他人员在线浏览。

**Acceptance**:
1. 建立两级以上子文件夹，上传后刷新目录和文件均保留；允许重命名文件夹。
2. PDF 可在线查看；Excel `.xls`、`.xlsx` 在线阅读，包含多个工作表、合并单元格、图片、签章。
3. 同一目录同名文件须明确选择新增版本或改名；历史版本可查看，原件保存。
4. 文件可注明关联某个零件/安装包，或属于整份资料包。
5. 非质量人员无维护入口，直接调用维护接口也被拒绝。

### User Story 3 - 提交及整包批准追溯 (P1)

质量人员登记每次客户提交，固定当次目录、文件版本、关联对象及组成。整包统一记录客户反馈和批准结果，无明细级批准。

**Acceptance**:
1. 提交日期与批准日期独立；提交不会被视为批准。
2. 补交新增提交版本，旧版本仍能查看原目录及文件。
3. 批准结论绑定具体提交轮次；更新工作资料不会修改已有批准结论。
4. 支持已提交、需补充、临时批准、已批准、未批准。临时批准可记录条件和期限，到期显示提示。
5. 所有维护记录操作者及时间；历史日期不明时允许留空，不推断批准日期。

## Functional Requirements

- **FR-001**: PPAP 位于零件模块下，两公司分别保存、筛选和切换。
- **FR-002**: 档案含台账号、名称、客户、负责人、计划提交日期、备注、关联明细。
- **FR-003**: 关联明细支持零件、安装包、模具号、模具类型、件号、名称、图纸版本。
- **FR-004**: 支持多级目录、重命名、根目录及子目录上传，目录名称不可作为实际磁盘路径。
- **FR-005**: 原文件不可因上传新版而丢失；同名冲突显式处理。
- **FR-006**: 已完成 PDF/Excel 可在线预览；预览转换失败时明确显示原因并可重试，原件保留。
- **FR-007**: 质量部门拥有维护权限；其他岗位只读。使用服务端身份决定权限。
- **FR-008**: 每轮提交保存完整快照；整包统一批准，可登记临时批准条件、期限及凭证。
- **FR-009**: 切换公司或输入其他公司资源 ID 不能访问错误公司的目录、文件、历史。
- **FR-010**: 并发修改检测冲突，防止旧页面覆盖新资料。
- **FR-011**: 可查询上传、重命名、提交和反馈操作历史。

## Edge Cases

- 空文件、损坏文件、扩展名伪装、同目录重名、非法目录名、跨档案目录 ID、跨公司 ID。
- 更新文件后查看旧提交、旧批准；改变工作关联后历史关联不变。
- 转换器不可用或超时、旧 Excel、多工作表、宽表、图片及中文。
- 质量人员同时维护；过期客户端需重新加载后再保存。

## Success Criteria

- 两家公司各完成建档→关联→多级目录→上传→预览→提交→临时批准→补交的真实流程。
- 测试样本 Excel 至少两个工作表、合并单元格和图片均在预览中可读；PDF 可在线查看。
- 非质量人员维护请求全部返回禁止；读请求成功。
- 旧提交文件内容与上传时校验值一致，后续更新不影响历史。
- 前端真实浏览器验收与 API/数据库验收分别留证。

## Assumptions

- 文档在本地软件制作完成；本期进行归档和查看。
- 默认单文件上限 100 MiB；仅接受 PDF、XLS、XLSX。
- 只读用户允许获取在线预览；原始文件下载仅质量部门可用。
- 超级管理员在现有验收模式下可维护，正式模式也必须属于质量部门；不会因职级高而自动拥有维护权限。
- 历史批准可直接登记一轮历史提交，日期允许留空。
